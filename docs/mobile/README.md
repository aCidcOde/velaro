# Mobile

## Escopo da versão 1.0

A camada mobile do CodaFácil Scaffold oferece uma API mínima e operacional para espelhar o domínio base do sistema.

Inclui:

- autenticação por bearer token
- dashboard resumido
- CRUD de clientes
- CRUD de produtos
- CRUD de pedidos

## Objetivo

Servir como ponto de partida para aplicativos mobile que precisem operar o mesmo núcleo de dados do front autenticado.
