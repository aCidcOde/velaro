# 114 - CodaFácil IA

O CodaFácil IA é um módulo técnico **local** incluído no core como referência de chat, upload e processamento assíncrono. Não depende de nenhum serviço externo.

## Escopo

- chat persistido
- upload PDF
- job assíncrono de resposta
- job assíncrono de processamento de upload
- comando agendável de sincronização

## O que não pertence ao core

- OpenAI real
- n8n
- Google Drive
- qualquer workflow externo acoplado
